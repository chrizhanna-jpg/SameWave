ripple.mp3
===========

Source:  "moving around in water- woosh, splash" by morganveilleux
URL:     https://freesound.org/people/morganveilleux/sounds/390006/
Licence: Creative Commons 0 (CC0 / public domain)

Processing (ffmpeg):
  - HQ MP3 preview from Freesound CDN
  - Trim: start ~0.35 s, length ~0.95 s (hand moving through water)
  - highpass 100 Hz, lowpass 6500 Hz
  - Soft fades: in 0.08 s, out 0.25 s (qsin)
  - loudnorm I=-23 LUFS, TP=-3 dBFS
  - Encode: mono 44.1 kHz MP3 @ 128 kb/s

Used only for Match "Offer a Ripple" (right-hand button).
