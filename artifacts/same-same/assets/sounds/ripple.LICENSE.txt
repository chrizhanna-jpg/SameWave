ripple.mp3
===========

Source:  "moving around in water- woosh, splash" by morganveilleux
URL:     https://freesound.org/people/morganveilleux/sounds/390006/
Licence: Creative Commons 0 (CC0 / public domain)
         https://creativecommons.org/publicdomain/zero/1.0/

Processing (ffmpeg):
  - HQ MP3 preview from Freesound CDN
  - Trim: start ~0.35 s, length ~0.95 s (hand moving through water)
  - highpass 100 Hz, lowpass 6500 Hz; soft fades
  - Tape-style slowdown ~0.8×: asetrate=35280, aresample=44100
    (pitch drops with speed; duration ≈ 1.23 s)
  - Gain +2.5 dB, fade-out ~0.22 s (qsin) from 1.02 s
  - alimiter true-peak ≤ −3 dBFS; integrated ≈ −23 LUFS
  - Encode: mono 44.1 kHz MP3 @ 128 kb/s

Used only for Match "Offer a Ripple" (right-hand button).
Prior 0.99 s cut is in git history (not bundled).
